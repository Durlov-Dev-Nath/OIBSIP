## Overview
This folder contains a professional, tri-fold brochure design project completed for "Dream House" real estate brand as part of the Oasis Infobyte internship, showcasing layout design, typography hierarchy, and print-media principles.

## Design Specifications
* **Format:** Tri-fold Brochure (6 Panels)
* **Typography:** Professional serif/sans-serif combination optimized for body text.
* **Brand Identity:** Cohesive color palette (Green & Navy Blue) and unified brand presentation.

## Deliverables
* Print-ready PDF file (`Brochure_Layout_Print.pdf`).
* High-resolution Preview PNG files.
