# Task 03 – Business Card Design

## Track
**Graphic Design**

## Task
**Task 03 – Business Card Design**

## Overview
This folder contains a professional, double-sided business card designed for the "Dream House" real estate brand, demonstrating typography balance and brand consistency as part of the Oasis Infobyte internship.

## Design Specifications
* **Dimensions:** 85mm × 55mm (Standard Business Card Size)
* **Bleed Area:** 3mm included on all sides for print-readiness.
* **Typography:** Limited to 2 font families for maximum readability and clean look.

## Features Included
* **Front Side:** Dream House company logo, full name, and job title.
* **Back Side:** Complete contact details (phone, email, website) and social media handles.
* **Brand Consistency:** Uses the identical color scheme and logo from Task 2.

## Deliverables
* Print-ready PDF file (`Business_Card_PDF.pdf`).
* High-resolution Preview PNG files.
* Vector Source File (`Business_Card_Source.ai`).
